# Lucas Oliveira Santos — Desenvolvimento Web

Projeto de Lucas Oliveira Santos para aprender desenvolvimento web na prática, construir um portfólio no GitHub e desenvolver um negócio de criação e manutenção de sites para pequenos comércios.

## Projeto 1 — Desenvolvimento Web Freelancer

O trabalho começa pelo site profissional de Lucas. Em seguida, serão criados sites demonstrativos, pesquisados possíveis clientes manualmente e apresentadas propostas aos proprietários interessados. Após a venda, o trabalho inclui entrega, gestão do projeto e manutenção contratada.

- **Desenvolvimento.** Definir com o cliente o escopo, os conteúdos, o prazo e a entrega do site.
- **Manutenção mensal.** Definir quais atualizações estão incluídas, como serão solicitadas e quais serviços terão orçamento separado. Combinar a responsabilidade por domínio e hospedagem antes da entrega.
- **Portfólio.** Identificar claramente as demonstrações e publicar projetos reais apenas com autorização para usar o nome, a marca e os materiais do cliente.

## Projeto 2 — Plataforma de automação com IA

Ideia futura inspirada na Zuzyia. A aplicação poderá ajudar a identificar comércios sem site, organizar informações públicas de fontes autorizadas e gerar demonstrações personalizadas para revisão humana. Este projeto permanece no planejamento. A validação do processo manual, das fontes permitidas e dos custos antecede qualquer implementação.
